================================================================================
INSTRUCCIONES PARA PROBAR LOS SERVICIOS CON POSTMAN
================================================================================

PREREQUISITOS:
- MySQL debe estar corriendo
- Las bases de datos deben estar creadas:
  * db_gimnasio_auth
  * db_gimnasio_socios
  * db_gimnasio_membresias
- Los servicios deben estar ejecutándose

================================================================================
1. SERVIDOR EUREKA
================================================================================

URL: http://localhost:8761

Descripción: Servidor de registro y descubrimiento de servicios (no tiene endpoints REST)

Verificar:
- Abre en navegador: http://localhost:8761
- Deberías ver el dashboard de Eureka con los servicios registrados

================================================================================
2. API GATEWAY
================================================================================

Puerto: 8080
URL Base: http://localhost:8080

Descripción: Gateway que redirecciona las requests a los microservicios

ENDPOINTS:
- Todas las rutas se redirecciona automáticamente a través del gateway

Ejemplo:
Método: GET
URL: http://localhost:8080/api/auth/registrar
(Se redirecciona automáticamente a http://localhost:8081/api/auth/registrar)

================================================================================
3. SERVICIO AUTENTICACION
================================================================================

Puerto: 8081
URL Base: http://localhost:8081

ENDPOINT 1: REGISTRAR USUARIO
Método: POST
URL: http://localhost:8081/api/auth/registrar

Headers:
Content-Type: application/json

Body (JSON):
{
  "username": "usuario1",
  "password": "password123",
  "rol": "ADMIN"
}

Respuesta esperada (200 OK):
{
  "id": 1,
  "username": "usuario1",
  "password": "$2a$10$...",
  "rol": "ADMIN"
}

EJEMPLOS DE USUARIOS PARA CREAR:
Usuario 1:
{
  "username": "admin",
  "password": "admin123",
  "rol": "ADMIN"
}

Usuario 2:
{

================================================================================
CÓDIGOS DE RESPUESTA ESPERADOS
================================================================================

200 OK: Operación exitosa
201 Created: Recurso creado exitosamente
400 Bad Request: Datos invalidos en el request
404 Not Found: Recurso no encontrado
500 Internal Server Error: Error en el servidor

================================================================================
NOTAS IMPORTANTES
================================================================================

- Las contraseñas se guardan encriptadas en la base de datos (BCrypt)
- Los IDs se generan automáticamente (auto-increment)
- Asegúrate que MySQL esté corriendo antes de hacer requests
- Todos los servicios deben estar ejecutándose para que funcione correctamente
- Si ves errores de conexión, verifica que las bases de datos existan
- Las URLs son sensibles a mayúsculas/minúsculas
